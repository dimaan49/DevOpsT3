# AuctionHub — HTTP API

Базовый URL: `http://localhost:8080`

Все запросы и ответы — JSON в кодировке UTF-8.

---

## Аутентификация

Полноценной аутентификации пока нет. Эндпоинты, требующие идентификации пользователя, читают заголовок `X-User-Id`:

```
X-User-Id: 42
```

Значение — идентификатор пользователя в системе. Заголовок обязателен для эндпоинтов, помеченных ниже как «требует X-User-Id».

---

## Формат ошибок

Все ошибки возвращаются в едином формате:

```json
{
  "error": "not_found",
  "message": "Auction 42 not found"
}
```

Поле `error` — машиночитаемый код. Поле `message` — текст для отображения пользователю.

| Код | `error` | Когда возвращается |
|-----|---------|--------------------|
| 400 | `bad_request` | Некорректный JSON, отсутствуют обязательные поля, неверный формат |
| 401 | `unauthorized` | Нет заголовка `X-User-Id` или пользователь не найден |
| 403 | `forbidden` | Пользователь не имеет прав на операцию |
| 404 | `not_found` | Объект не найден |
| 409 | `conflict` | Операция невозможна в текущем состоянии |
| 500 | `internal_error` | Внутренняя ошибка сервера |
| 503 | `service_unavailable` | База данных недоступна (только `/health`) |

## Healthcheck

### `GET /health`

Проверка работоспособности сервиса. Не требует аутентификации.

**Ответ 200:**

```json
{
  "service": "auctionhub",
  "status": "ok",
  "database": "ok"
}
```

**Ответ 503** (если БД недоступна):

```json
{
  "service": "auctionhub",
  "status": "degraded",
  "database": "down"
}
```

## Пользователи

### `POST /api/users`

Регистрация нового пользователя.

**Тело запроса:**

```json
{
  "email": "user@example.com",
  "password": "secret123",
  "role": "seller",
  "age_confirmed": true
}
```

**Поля:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `email` | string | да | Email, уникальный в системе |
| `password` | string | да | Минимум 6 символов |
| `role` | string | да | `seller`, `bidder` или `moderator` |
| `age_confirmed` | boolean | да | Должно быть `true` |

**Ответ 201:**

```json
{
  "id": 1,
  "email": "user@example.com",
  "role": "seller"
}
```

**Ошибки:**

- `400` — отсутствуют поля, неверный формат email, короткий пароль, неверная роль, не подтверждён возраст
- `409` — email уже зарегистрирован

---

### `GET /api/users/{id}`

Получить пользователя по id.

**Ответ 200:**

```json
{
  "id": 1,
  "email": "user@example.com",
  "role": "seller",
  "age_confirmed": true,
  "created_at": "2026-09-12T17:00:00Z"
}
```

Поле `password_hash` никогда не возвращается.

**Ошибки:**

- `404` — пользователь не найден

## Аукционы

### `POST /api/auctions`

Создать аукцион. Требует `X-User-Id`. Только для роли `seller`.

**Тело запроса:**

```json
{
  "title": "Антикварные часы",
  "description": "Часы XIX века",
  "step": 100,
  "start_price": 1000
}
```

**Поля:**

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| `title` | string | да | Название аукциона |
| `description` | string | нет | Описание |
| `step` | number | да | Шаг аукциона, > 0 |
| `start_price` | number | да | Начальная цена, > 0 |

**Ответ 201:** объект аукциона (см. ниже).

**Ошибки:**

- `400` — невалидные поля
- `401` — нет `X-User-Id` или пользователь не найден
- `403` — пользователь не `seller`

---

### `GET /api/auctions`

Список всех аукционов. Не требует аутентификации.

**Ответ 200:**

```json
{
  "items": [
    {
      "id": 1,
      "seller_id": 1,
      "title": "Антикварные часы",
      "description": "Часы XIX века",
      "step": 100,
      "start_price": 1000,
      "status": "active",
      "created_at": "2026-09-12T17:00:00Z"
    }
  ],
  "count": 1
}
```

---

### `GET /api/auctions/{id}`

Детали аукциона с лотами. Не требует аутентификации.

**Ответ 200:** объект аукциона с полем `lots` — массив лотов.

**Ошибки:**

- `404` — аукцион не найден

---

### `POST /api/auctions/{id}/publish`

Опубликовать аукцион. Требует `X-User-Id`. Только владелец.

Переводит статус из `draft` в `active`.

**Ответ 200:** объект аукциона со `status: active`.

**Ошибки:**

- `401` — нет `X-User-Id`
- `403` — не владелец
- `404` — аукцион не найден
- `409` — аукцион не в статусе `draft`

---

### `POST /api/auctions/{id}/cancel`

Отменить аукцион. Требует `X-User-Id`. Только владелец.

Отмена возможна, если:

- статус `draft` или `active`;
- по лотам аукциона нет ни одной ставки.

**Ответ 200:** объект аукциона со `status: cancelled`.

**Ошибки:**

- `401` — нет `X-User-Id`
- `403` — не владелец
- `404` — аукцион не найден
- `409` — аукцион `finished` или `cancelled`, либо по лотам есть ставки

---

### `POST /api/auctions/{id}/lots`

Добавить лот к аукциону. Требует `X-User-Id`. Только владелец.

**Тело запроса:**

```json
{
  "title": "Часы с кукушкой",
  "description": "Рабочие",
  "start_price": 1000
}
```

**Ответ 201:** объект лота.

**Ошибки:**

- `400` — невалидные поля
- `401` — нет `X-User-Id`
- `403` — не владелец
- `404` — аукцион не найден

## Ставки

### `POST /api/lots/{id}/bids`

Сделать ставку. Требует `X-User-Id`.

**Правило предметной области:**

- ставка должна быть строго выше текущей максимальной;
- разница между новой ставкой и текущей должна быть кратна шагу аукциона;
- аукцион должен быть в статусе `active`.

**Тело запроса:**

```json
{
  "amount": 1200
}
```

**Ответ 201:** объект ставки.

**Ошибки:**

- `400` — нет поля `amount` или `amount <= 0`
- `401` — нет `X-User-Id`
- `403` — роль пользователя не позволяет делать ставки
- `404` — лот не найден
- `409` — аукцион не активен, ставка ниже текущей или не кратна шагу

---

### `GET /api/lots/{id}/bids`

История ставок по лоту. Не требует аутентификации.

**Ответ 200:**

```json
{
  "lot_id": 1,
  "current_price": 1200,
  "items": [
    {
      "id": 2,
      "lot_id": 1,
      "bidder_id": 2,
      "amount": 1200,
      "created_at": "2026-09-12T17:05:00Z"
    }
  ],
  "count": 1
}
```

Поле `current_price` — текущая максимальная ставка или начальная цена лота, если ставок нет.

**Ошибки:**

- `404` — лот не найден

---

## Статусы аукциона

| Статус | Описание |
|--------|----------|
| `draft` | Черновик, ещё не опубликован. Ставки невозможны. |
| `active` | Активен, принимает ставки. |
| `finished` | Завершён (пока только вручную, автоматика — позже). |
| `cancelled` | Отменён продавцом. Ставки невозможны. |
